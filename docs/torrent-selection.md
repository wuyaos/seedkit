# 选择种子内容

取消勾选只改变新种子包含的文件，不会删除、移动或重写源文件。筛选后的种子文件集合与 InfoHash 可能不同；辅种时应保持与原种子一致。蓝光原盘内部文件不建议随意排除。

## 使用

在主操作区或右键快捷制种参数中打开“选择文件”。默认选择所有可选文件；取消目录会取消该目录下全部可选文件，包含折叠及被搜索隐藏的项。目录显示全部、部分、未选三种状态。搜索只过滤展示，不改变选择。

应用只保存草稿，不立即制种；取消丢弃未应用更改。恢复默认选择重新选中当前规则允许的文件，不修改已保存的全局配置。主操作区和快捷制种的选择草稿分别绑定源路径，不能将一个目录的选择应用到另一个目录。

设置中的 `torrent.exclude` 是默认排除规则，每条一个 glob。单次任务可以跟随配置、填写替代规则或使用空列表关闭用户排除规则。内置忽略仍然有效。规则命中的文件显示原因，不可直接勾选；先修改规则并重新扫描，才能恢复为可选项。手动取消项在重新扫描时保留仍有效的部分。

示例：`*.log` 排除所有深度的 log 文件；`Sample/**` 排除源目录直接下属的 Sample 内容；`**/Sample/**` 排除任意层级的 Sample 内容。匹配大小写不敏感，Windows 分隔符统一为 `/`。内置忽略包含 `.torrent`、系统杂项与 `@eaDir`；符号链接在选择流程中不可选，避免读取所选目录外内容。不支持 `!` 反选、绝对路径及 `..` 逃逸。

应用后文件清单固定。开始执行前会重新检查扫描快照，文件新增、删除或元数据变化时需要重新扫描确认。哈希期间也应保持源文件稳定；元数据检查不是对恶意并发修改的完整防护，不能识别保留大小与时间戳的内容篡改。

## API

`POST /api/torrent/preview`（需要登录）：

```json
{"Path":"data/Movie", "Exclude":["*.log"]}
```

返回扁平 `files` 清单、`snapshot`、`isDir` 和 `totalBytes`。每个文件有相对 `path`、`size`、`mtime` 及 `reason`；空 `reason` 表示可选。禁止把 `mtime` 当作内容哈希使用。

`POST /api/torrent` 在原参数上增加：

```json
{
  "Path":"data/Movie",
  "Exclude":[],
  "Selection":{"snapshot":"预览返回的快照", "paths":["main.mkv","sub.zh.srt"]}
}
```

`Exclude` 缺省时跟随全局设置，`[]` 显式不使用用户排除规则。选择清单必须来自同一源路径、同一规则的最新快照，路径逐字匹配，不能使用通配符代替精确文件。未提供 `Selection` 时按有效规则制种；没有用户规则且未手动选择时保持原有制种路径。

预览不计算文件内容哈希。大目录扫描耗时与目录规模有关，可取消；超过实现上限会明确报错，而不是返回不完整的可应用清单。

## 制种兼容边界

无用户排除规则、未应用手动选择时，继续使用原来的 mkbrr 制种路径。使用筛选时按精确路径流式生成标准 BitTorrent v1 种子，不复制媒体文件，也不把文件名当作 glob。

筛选路径的自动分块从 256 KiB 开始，按所选总大小逐步增加，目标约 2048 块，上限 16 MiB；显式分块支持 16 KiB–64 MiB。这不是 mkbrr 的 tracker 专用分块策略，辅种不能仅凭“自动”参数假设 InfoHash 相同。零长度文件保留在文件清单中。

扫描最多接受 100000 个目录条目，规则最多 1000 条；超限会报错。筛选路径的分块哈希元数据上限为 32 MiB，超过时需增大分块或缩小制种内容。
