## Container system packages

The runtime uses Alpine Linux 3.21 packages, including FFmpeg, its shared libraries, CA certificates, time-zone data and WenQuanYi fonts. These are separate system components with their own licenses, not relicensed as seedkit. Package versions can be inspected using `apk info -v` inside the image; FFmpeg build options and license can be inspected with `ffmpeg -buildconf` and `ffmpeg -L`. Package metadata, build recipes and source locations are available from [Alpine packages](https://pkgs.alpinelinux.org/packages?branch=v3.21) and [Alpine aports](https://gitlab.alpinelinux.org/alpine/aports/-/tree/3.21-stable).

The source repository and revision are included in OCI image labels. Keep source, dependency versions/checksums, build instructions and these notices available when redistributing modified builds.
