# Agent Note: 文件导航偏好与结果区滚动边界

Status: implemented

## Problem

文件管理缺少固定入口和路径跳转；长报告、成组截图会把复制、下载按钮推到可视区域之外。结果区嵌套卡片还会和文件列表的平铺风格割裂。

## Decision

Home 是当前浏览器的导航偏好，保存在 `sk.home`，不写服务器配置、不改变服务端允许访问的根目录。首次进入优先恢复当前标签页的 `sk.cwd`，没有记录时使用 Home；目录失效时退回根目录列表。路径输入使用根目录别名下的虚拟路径，不将服务器绝对路径当作导航入口。跳转失败保留原目录和文件列表；请求只接受最新一次导航的响应。

任务勾选同样属于当前浏览器偏好，保存在 `sk.ops`。切换文件只按文件类型和工具可用性临时禁用不支持的任务，不覆盖用户的原始勾选。右键截图与制种先复制当前参数到独立草稿，并捕获目标路径；取消不提交，确认只覆盖本次执行，不回写常规参数或偏好。相比直接复用常规参数对象，这样不会让一次快捷操作悄悄改变下一次任务。

结果内容和底部操作栏分开布局：内容独立滚动，按钮不属于滚动正文。结果存在时，上方参数区最多占右栏的 44%，参数展开后在其内部滚动，为结果和底部按钮留空间。结果区不增加第二层玻璃卡片，只通过标签选中态和细分隔线区分区域。

图标使用本地 SVG sprite。此处原先以 `no-cache` 避免旧图标滞留的缓存决定，由[按内容版本缓存图标](../bug-fix/2026-10-31-versioned-icon-cache.md)替代；本篇保留导航、任务偏好与结果布局的约束。

## Alternatives considered

- 服务端统一配置 Home 便于跨设备同步，但会让个人导航习惯影响其他用户，并增加配置接口；当前偏好保持浏览器本地。
- 继续让整个右栏滚动最简单，但长报告仍会把操作栏推走，不能满足随时复制、下载的要求。
- 在正文上覆盖悬浮按钮能节省布局改动，但会遮挡报告或图片；使用正常文档流中的固定高度操作区。

## Consequences

导航无需新增服务端接口或请求轮询。参数与结果各有滚动区域，长内容不会撑开页面，但小高度窗口内可读正文仍受屏幕空间限制。偏好不跨浏览器同步，服务器根目录变化后需重新设置 Home。

现有架构笔记仅约束后端模块边界，与本篇部分相关但不冲突：[单二进制架构](../architecture/2026-10-31-single-static-binary.md)。本篇不替代它。
